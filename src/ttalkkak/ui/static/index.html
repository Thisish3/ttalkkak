서빙 구성 실행

모델을 고르면 GPU에 맞는 엔진 설정 후보를 만들고, 실제로 띄워 정확도·처리량·에이전트 준비 상태를 잰 뒤 하나를 고릅니다.

1. 모델 선택

Hugging Face에서 검색하거나 ID를 직접 입력합니다. NIM 모델은 nim:으로 시작합니다.

모델다운로드가중치이 GPU
검색어를 입력하세요
선택한 모델

2. skill 선택

에이전트에 붙일 도구입니다. 모델이 tool calling·structured output을 제대로 하는지도 함께 검사합니다.

3. 실행

후보마다 엔진을 띄우고 검증합니다. 한 번에 하나의 run만 실행합니다.

4. 결과

최근 run 10개. 누르면 리포트를 봅니다.
