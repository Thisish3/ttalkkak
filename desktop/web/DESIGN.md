# 디자인 방향 (11a)

대상: GPU 한 장으로 LLM을 서비스하는 운영자. 하루 종일 켜 두는 계기판 같은 도구이므로 장식보다 밀도와 읽기 쉬움이 우선이다.

- **구조**: 왼쪽 사이드바(아이콘+이름 6개), 위쪽 28px 상태 줄(서버 주소, 칩 배지, 연결 점), 가운데 패널. 브라우저 모드에서도 같은 구조.
- **색**: 차가운 회녹색 중성 바탕 + 잉크 청록 강조 하나. 따뜻한 크림/테라코타, 검정+형광 조합은 쓰지 않는다. 상태 색(정상/주의/오류)은 항상 기호(●, ▲, ✕)와 글자를 같이 쓴다. 밝은/어두운 테마는 `prefers-color-scheme`을 따른다.
- **글꼴**: OS 기본(`system-ui`, 한글은 Apple SD Gothic Neo / Malgun Gothic / Noto Sans KR). 숫자는 `tabular-nums`로 자릿수를 맞추고 표에서는 오른쪽 정렬. 본문 13px, 촘촘한 줄 간격.
- **한 군데만 눈에 띄게**: 상태 줄의 칩 배지 "GPU 한 장 · 최대 복제본 N개"에 복제본 칸을 작은 네모 N개로 그린다. 나머지는 조용하게 둔다.
- **모양**: 모서리 4px 하나, 카드 그림자 없이 1px 선만 사용. 움직임은 사용자 동작에 반응하는 것(포커스, 눌림)만.
- **토큰**: 색·간격·글꼴·크기는 모두 `app.css`의 `:root`에 있다. 어두운 테마는 같은 이름을 다시 정의한다.
