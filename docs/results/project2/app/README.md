# 10절: 맥 앱 화면 확인 (R20) — 2026-11-18 맥 세션

연결: 맥 → `ssh -N -L 18765:100.68.102.113:8787 desk`(Tailscale SSH 승인) → 앱 서버 주소 `http://127.0.0.1:18765`.
맥의 Tailscale은 userspace 모드라 앱이 100.x로 직접 나가지 못해 터널을 썼다.

## 어떻게 확인했나
- `01-live-top.png`: 데스크탑 앱(Tauri dev 빌드) 창을 `screencapture -l`로 찍은 것. 화면 기록 권한은 ClaudeCode에 사용자가 허용.
- `02`~`04`: 앱의 손쉬운 사용 권한이 없어 앱 창을 스크롤할 수 없었다. 그래서 **같은 화면 파일(desktop/web)** 을 맥 Chrome에 띄우고, 로컬 프록시(127.0.0.1:18766)가 `/api/*`에만 운영자 토큰을 붙여 같은 터널로 넘기게 해서 찍었다. 데이터와 렌더 코드는 앱과 같고, 앱 고유 기능(키체인, OS 알림, 네이티브 메뉴)은 이 방법으로 확인되지 않는다.

## 발견한 문제
- 부하 시험 그래프의 y축 위 라벨이 왼쪽에서 잘린다("115 ms"로 보이지만 실제 최대는 1초가 넘음 — 목표 1초 선보다 점이 위에 있다). SVG viewBox가 작고 `width: 100%`라 10px 글자가 크게 확대되어 viewBox 밖으로 나간다(`desktop/web/app.css` `.chart`, `app.js` `loadtestChart`).
- 갱신은 "응답이 끝난 뒤 2초"라 원격(터널)에서는 2초보다 길다(약 3.3초).
